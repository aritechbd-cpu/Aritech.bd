Free hosting:
1. Create a GitHub account and a new public repository.
2. Upload index.html and the complete assets folder (keep the same folder structure).
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main / root, and Save.

Order flow:
The order form calculates an estimate and opens WhatsApp with the completed order message.
The customer must press Send in WhatsApp. This static site does not store orders in a database.
